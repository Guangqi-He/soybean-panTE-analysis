# TE library benchmark

This document describes an example workflow for benchmarking different TE libraries on a single soybean reference genome. The same procedure can be repeated for other genomes or libraries.

## Purpose

The goal is to compare TE annotation results generated by different TE libraries and to evaluate their consistency using the EDTA `lib-test.py` utility.

## Required tools

- RepeatMasker
- EDTA, including `lib-test.py`
- Python 3

## Required input files

- `Wm82.fasta`: reference genome sequence
- `Wm82.EDTA.TElib.fa`: TE library generated by EDTA for the reference genome
- `SoyTEdb.family.fa`: family-level SoyTEdb library
- `panTE_DeepTE_final.lib.fa`: final pan-genome TE library

## Step 1. Annotate the same genome with different TE libraries

Run RepeatMasker separately for each TE library. Because RepeatMasker generates output files using the genome name by default, rename the `.out` file after each run to avoid overwriting previous results.

```bash
# Annotation using the genome-specific EDTA TE library
RepeatMasker -e ncbi -pa 36 -q -no_is -norna -nolow -div 40 -lib Wm82.EDTA.TElib.fa -cutoff 225 Wm82.fasta
mv Wm82.fasta.out Wm82.EDTAlib.out

# Annotation using the SoyTEdb family-level library
RepeatMasker -e ncbi -pa 36 -q -no_is -norna -nolow -div 40 -lib SoyTEdb.family.fa -cutoff 225 Wm82.fasta
mv Wm82.fasta.out Wm82.SoyTEdb.out

# Annotation using the final pan-genome TE library
RepeatMasker -e ncbi -pa 36 -q -no_is -norna -nolow -div 40 -lib panTE_DeepTE_final.lib.fa -cutoff 225 Wm82.fasta
mv Wm82.fasta.out Wm82.panTElib.out
```

## Step 2. Compare annotation results with EDTA lib-test

In this example, the SoyTEdb-based annotation is first used as the reference, and the EDTA or pan-genome TE library annotation is used as the test set.

```bash
# Compare the EDTA library annotation against the SoyTEdb annotation
python3 lib-test.py --genome Wm82.fasta --test Wm82.EDTAlib.out --reference Wm82.SoyTEdb.out

# Compare the pan-genome TE library annotation against the SoyTEdb annotation
python3 lib-test.py --genome Wm82.fasta --test Wm82.panTElib.out --reference Wm82.SoyTEdb.out

# Reverse comparison: use the pan-genome TE annotation as the reference
python3 lib-test.py --genome Wm82.fasta --test Wm82.SoyTEdb.out --reference Wm82.panTElib.out
```

## Main output files

- `<test>.repeatmasker.lib.report`: per-category sensitivity, specificity, accuracy, precision, FDR, and F1 score
- `<test>.superfamily_confusion_matrix.tsv`: superfamily-level confusion matrix
- `<test>.sequence_assessment.report`: per-sequence and per-category assessment when an extended report is generated

## Notes

- All libraries should be formatted consistently at the family level before comparison.
- The same RepeatMasker parameters should be used for all libraries to ensure a fair comparison.
- The `.out` files should be renamed immediately after each RepeatMasker run to prevent overwriting.
