# RT domain phylogenetic analysis

This document describes an example workflow for extracting reverse transcriptase (RT) domains from TEsorter output, reducing redundancy using MMseqs2, and constructing phylogenetic trees.

## Purpose

The goal is to compare the sequence diversity of representative RT domains from major LTR retrotransposon subfamilies.

## Required tools

- seqkit
- seqtk
- MMseqs2
- MAFFT
- IQ-TREE 3

## Required input files

- `Wm82.dom.faa`: protein domain FASTA file generated by TEsorter
- `sample_metadata.tsv`: sample metadata table containing sample ID and ecotype

## Step 1. Extract RT domains for one Copia subfamily and one Gypsy subfamily

This example uses `SIRE:Ty1-RT` and `CRM:Ty3-RT` from one genome. The same logic can be applied to other subfamilies.

```bash
# Extract SIRE RT domains from Copia elements
seqkit grep -r -p 'SIRE:Ty1-RT' Wm82.dom.faa \
  | seqkit replace -p '.+' -r 'Wm82_SIRE_{nr}' \
  > Wm82_SIRE_RT.faa

# Extract CRM RT domains from Gypsy elements
seqkit grep -r -p 'CRM:Ty3-RT' Wm82.dom.faa \
  | seqkit replace -p '.+' -r 'Wm82_CRM_{nr}' \
  > Wm82_CRM_RT.faa
```

## Step 2. Cluster RT domains using the 80-80-80 rule

The following command clusters RT sequences with at least 80% sequence identity and 80% alignment coverage.

```bash
mmseqs easy-cluster Wm82_SIRE_RT.faa Wm82_SIRE_RT tmp \
  --min-seq-id 0.8 -c 0.8 --cov-mode 0 --threads 48

mmseqs easy-cluster Wm82_CRM_RT.faa Wm82_CRM_RT tmp \
  --min-seq-id 0.8 -c 0.8 --cov-mode 0 --threads 48
```

The representative sequences are written to:

```text
Wm82_SIRE_RT_rep_seq.fasta
Wm82_CRM_RT_rep_seq.fasta
```

## Step 3. Prepare representative RT sequences for tree construction

For a small example, the representative sequences can be used directly. For large datasets, random subsampling can be used to keep the tree readable.

```bash
# Randomly sample up to 100 representative sequences from one subfamily
seqtk sample -s666 Wm82_SIRE_RT_rep_seq.fasta 100 > SIRE_RT.tree_input.fa
seqtk sample -s666 Wm82_CRM_RT_rep_seq.fasta 100 > CRM_RT.tree_input.fa
```

## Step 4. Multiple sequence alignment

```bash
mafft --thread 32 --auto SIRE_RT.tree_input.fa > SIRE_RT.tree_input.fa.aln
mafft --thread 32 --auto CRM_RT.tree_input.fa > CRM_RT.tree_input.fa.aln
```

## Step 5. Phylogenetic tree construction

```bash
iqtree3 -s SIRE_RT.tree_input.fa.aln -bb 1000 -nt AUTO -T 32
iqtree3 -s CRM_RT.tree_input.fa.aln -bb 1000 -nt AUTO -T 32
```

## Step 6. Prepare annotation files for tree visualization

```bash
grep '^>' SIRE_RT.tree_input.fa | sed 's/^>//' > SIRE_RT_tree.id
grep '^>' CRM_RT.tree_input.fa | sed 's/^>//' > CRM_RT_tree.id
```

A simple tree annotation table can be generated from sequence IDs. In this naming scheme, the ID format is `sample_family_number`.

```bash
awk 'BEGIN{OFS="\t"} {
  split($1, a, "_");
  print $1, a[2], a[1]
}' SIRE_RT_tree.id > SIRE_RT_tree.annotation.tsv

awk 'BEGIN{OFS="\t"} {
  split($1, a, "_");
  print $1, a[2], a[1]
}' CRM_RT_tree.id > CRM_RT_tree.annotation.tsv
```

## Notes

- Copia subfamilies can include SIRE, Ivana, Ikeros, TAR, and Ale.
- Gypsy subfamilies can include CRM, Athila, Reina, Ogre, and Tekay.
- The original full analysis merged representative RT domains across ecotypes before sampling and tree construction.
- The example above intentionally uses one genome and two subfamilies to keep the workflow clear and reproducible.
