# Syntenic Diversity Analysis

This document provides a simplified workflow for calculating syntenic diversity using **SynDiv**. The commands are rewritten as a single-query-genome example and can be adapted to additional genomes or population groups.

## Overview

The workflow includes:

1. Preparing reference and query genome FASTA files.
2. Performing whole-genome alignment using `nucmer`.
3. Detecting syntenic and non-syntenic regions using `SyRI` and `SynDiv`.
4. Calculating genome-wide and window-based syntenic diversity.
5. Calculating subgroup-level syntenic diversity and Fst.

## Required software

- `seqkit`
- `MUMmer4`
- `SyRI`
- `SynDiv`
- `awk`, `grep`, `sort`, and other standard Linux utilities

## Input files

Example input files:

```text
Wm82.fasta
query.fasta
cultivar.txt
landrace.txt
wild.txt
```

`Wm82.fasta` is the reference genome.  
`query.fasta` is one example query genome.  
`cultivar.txt`, `landrace.txt`, and `wild.txt` contain sample names for population-level analysis.

## 1. Prepare chromosome-level FASTA files

Only the first 20 chromosomes were used in this analysis. The following command keeps the first 20 sequences from the query genome and renames them as `W82_01` to `W82_20` to match the reference chromosome naming style.

```bash
seqkit fx2tab query.fasta \
  | head -n 20 \
  | awk 'BEGIN{OFS="\t"} {printf("W82_%02d\t%s\n", NR, $2)}' \
  | seqkit tab2fx \
  > query.chr20.fasta
```

If the reference genome contains non-chromosomal scaffolds, a chromosome-only reference FASTA can be prepared in the same way:

```bash
seqkit fx2tab Wm82.fasta \
  | head -n 20 \
  | awk 'BEGIN{OFS="\t"} {printf("W82_%02d\t%s\n", NR, $2)}' \
  | seqkit tab2fx \
  > Wm82.chr20.fasta
```

## 2. Whole-genome alignment using nucmer

Align the query genome to the Wm82 reference genome.

```bash
nucmer -l 40 -g 90 -c 100 -b 200 -t 20 -p query Wm82.chr20.fasta query.chr20.fasta
```

Filter the alignment and generate coordinate information:

```bash
delta-filter -1 -i 90 -l 100 query.delta > query.filter.delta

show-coords -THrd query.filter.delta > query.coords
```

## 3. Generate alignment files for SynDiv

`SynDiv` requires alignment files generated by `show-aligns`. The example below shows the command for one chromosome.

```bash
show-aligns -r query.filter.delta W82_01 W82_01 > query.W82_01.aligns
```

For a complete genome-level analysis, generate the corresponding `show-aligns` output for all chromosomes included in the analysis and concatenate them into one file:

```bash
cat query.W82_01.aligns > query.aligns
```

In the full analysis, `query.aligns` should contain alignment records for all 20 chromosomes.

## 4. Identify syntenic regions using SyRI

Run `SyRI` using the filtered delta file and coordinate file.

```bash
syri -c query.coords -d query.filter.delta -r Wm82.chr20.fasta -q query.chr20.fasta --nc 5 --all --prefix query.
```

The main output file is:

```text
query.syri.out
```

Check whether the chromosome order and names are consistent between the alignment file and the SyRI output:

```bash
grep "Alignments between" query.aligns | head

cut -f1 query.syri.out | sort -u | head
```

## 5. Generate multi-intersection and coordinate files

Create the multi-intersection file from the SyRI output:

```bash
SynDiv_c multiinter -i query.syri.out -o soybean.multiinter.out
```

Generate syntenic coordinate information:

```bash
SynDiv_c coor -s soybean.multiinter.out -i query.aligns -o soybean.coord.out
```

## 6. Generate non-syntenic region files

Generate the sequence length file for the query genome:

```bash
seqkit fx2tab -n -l query.chr20.fasta > query.lengths
```

Identify non-syntenic regions:

```bash
SynDiv_c no_syn --coor soybean.coord.out --lengths query.lengths -o soybean_no_syn.out
```

Prepare a genome configuration file for non-syntenic sequence alignment:

```bash
printf "query\tquery.chr20.fasta\n" > genome_config.file
```

Generate non-syntenic alignments:

```bash
SynDiv_p -i soybean_no_syn.out -c genome_config.file --prefix soybean_no_syn_aligns
```

## 7. Calculate syntenic diversity

Calculate syntenic diversity for the full dataset:

```bash
SynDiv_c cal --fast \
  -r Wm82.chr20.fasta \
  --coor soybean.coord.out \
  --no_syn soybean_no_syn.out \
  --syri_outs soybean_no_syn_aligns.no_syn_alignment.out \
  --aligns query.aligns \
  -o soybean
```

Calculate window-based syntenic diversity using 300-kb windows and 150-kb steps:

```bash
SynDiv_c window \
  -r Wm82.chr20.fasta \
  -i soybean \
  -w 300000 \
  -s 150000 \
  -o soybean_window.pi
```

For finer-scale hotspot analysis, use 20-kb windows and 10-kb steps:

```bash
SynDiv_c window \
  -r Wm82.chr20.fasta \
  -i soybean \
  -w 20000 \
  -s 10000 \
  -o soybean_window_hot.pi
```

## 8. Calculate subgroup-level syntenic diversity

For subgroup analysis, prepare sample list files such as:

```text
cultivar.txt
landrace.txt
wild.txt
```

Each file should contain one sample name per line. The sample names should match the prefixes of the corresponding `.syri.out`, `.aligns`, and `.lengths` files.

Example for the cultivar group:

```bash
SynDiv_c multiinter \
  -i $(awk '{print $1".syri.out"}' cultivar.txt) \
  -o cultivar.multiinter.out

SynDiv_c coor \
  -s cultivar.multiinter.out \
  -i $(awk '{print $1".aligns"}' cultivar.txt) \
  -o cultivar.coord.out

SynDiv_c no_syn \
  --coor cultivar.coord.out \
  --lengths $(awk '{print $1".lengths"}' cultivar.txt) \
  -o cultivar_no_syn.out
```

Extract non-syntenic alignments for samples within the cultivar group:

```bash
awk 'NR==FNR {sample[$1]; next} ($1 in sample && $2 in sample)' \
  cultivar.txt \
  soybean_no_syn_aligns.no_syn_alignment.out \
  > cultivar_no_syn_alignment.out
```

Calculate syntenic diversity for the cultivar group:

```bash
SynDiv_c cal --fast \
  -r Wm82.chr20.fasta \
  --coor cultivar.coord.out \
  --no_syn cultivar_no_syn.out \
  --syri_outs cultivar_no_syn_alignment.out \
  --aligns $(awk '{print $1".aligns"}' cultivar.txt) \
  -o cultivar
```

Calculate window-based syntenic diversity for the cultivar group:

```bash
SynDiv_c window -r Wm82.chr20.fasta -i cultivar -w 300000 -s 150000 -o cultivar_window.pi
```

## 9. Calculate Fst between groups

After calculating syntenic diversity for each subgroup, pairwise Fst can be calculated using `SynDiv_c Fst`.

Domestication comparison:

```bash
SynDiv_c Fst -c wild landrace soybean -o domestication_Fst.out
```

Improvement comparison:

```bash
SynDiv_c Fst -c landrace cultivar soybean -o improvement_Fst.out
```

## Notes

- The single-query-genome commands above are intended to show the core logic of the analysis.
- In the complete population-scale analysis, the same workflow should be applied to all query genomes before running the multi-sample `SynDiv` commands.
- Chromosome naming must be consistent among the reference FASTA, query FASTA, SyRI output, and `show-aligns` files.
- The `show-aligns` step should include all chromosomes used in the analysis; otherwise, downstream coordinate and diversity calculations will be incomplete.
- Window size can be adjusted depending on the biological question. In this study, 300-kb windows with 150-kb steps were used for genome-wide analysis, whereas 20-kb windows with 10-kb steps were used for hotspot-level analysis.
