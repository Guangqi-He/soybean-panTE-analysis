# TAP and TIP identification

This document describes an example workflow for identifying TE absence polymorphisms (TAPs) and TE insertion polymorphisms (TIPs) from genome alignments and structural variant calls.

## Purpose

The goal is to identify insertion and deletion polymorphisms relative to the reference genome, annotate which variants are TE-derived, and assign their genomic positions relative to genes.

## Required tools

- meryl
- winnowmap
- samtools
- minipileup
- bcftools
- BEDtools
- RepeatMasker
- EDTA utility `classify_by_lib_RM.pl`
- VEP
- Python 3

## Required input files

- `Wm82.fasta`: reference genome
- `HJ117.fasta`: query genome assembly used as one example accession
- `Wm82.TE.bed`: TE annotation BED file for the reference genome
- `panTE_DeepTE_final.lib.fa`: final pan-genome TE library
- `Wm82.gff3.gz`: compressed and indexed gene annotation file
- `Wm82.fasta.gz`: compressed and indexed reference genome FASTA file

## Step 1. Align one query genome to the reference genome

```bash
ref=Wm82.fasta
query=HJ117.fasta
sample=HJ117

# Build repetitive k-mer list for Winnowmap
meryl count k=19 output Wm82.meryl ${ref}
meryl print greater-than distinct=0.9998 Wm82.meryl > Wm82_k19.txt

# Whole-genome alignment
winnowmap -ax asm5 --eqx -t 24 -W Wm82_k19.txt \
  ${ref} ${query} \
  > ${sample}.sam

samtools sort -O BAM -o ${sample}.bam ${sample}.sam
samtools index ${sample}.bam
```

## Step 2. Call insertion and deletion variants

```bash
minipileup -f ${ref} -v -c -C -q 0 -s 0 -a 0 -l 1000 \
  ${sample}.bam \
  > ${sample}.PAV.vcf

bcftools norm -m -any -f ${ref} ${sample}.PAV.vcf \
  -Oz -o ${sample}.PAV.norm.vcf.gz

bcftools index -t ${sample}.PAV.norm.vcf.gz
```

## Step 3. Convert genotypes into sample-level variant presence records

The custom script below summarizes which samples carry each variant. The `--any-hom` option is useful when multi-allelic homozygous genotypes such as `2/2` and `3/3` should also be treated as homozygous variant genotypes.

```bash
python3 minipileupVCF2bedGroup.py \
  -i population.PAV.norm.vcf.gz \
  -g sample_group.tsv \
  -o population.PAV.summary.tsv \
  --any-hom

# Remove sites without variant alleles in the selected samples
awk '$5 != "0/0/0"' population.PAV.summary.tsv \
  > population.PAV.summary.filtered.tsv
```

## Step 4. Annotate deletion variants overlapping reference TE copies

For deletions, the deleted sequence is directly located in the reference genome. Therefore, deletion intervals can be intersected with the reference TE annotation.

```bash
awk 'BEGIN{OFS="\t"} $4 == "DEL" {print $1, $2, $2 + $3, $4, $5, $6}' \
  population.PAV.summary.filtered.tsv \
  > population.DEL.bed

# Calculate overlap between deletions and reference TE copies
bedtools coverage \
  -a population.DEL.bed \
  -b Wm82.TE.bed \
  -wo \
  > population.DEL.TE.coverage.tsv

# Assign TE class to deletions when at least 10% of the deletion overlaps a TE
bedtools intersect \
  -a population.DEL.bed \
  -b Wm82.TE.bed \
  -f 0.1 -wo \
  > population.DEL.TE.class.tsv
```

## Step 5. Extract and classify insertion sequences

For insertions, the inserted sequence must be extracted from the VCF and classified by RepeatMasker using the pan-genome TE library.

```bash
python3 extract_vcf_seq.py \
  -i population.PAV.norm.vcf.gz \
  -t INS \
  --min 100 \
  -o population.insertions.fasta

RepeatMasker -e ncbi -pa 48 -q -no_is -nolow -div 40 \
  -lib panTE_DeepTE_final.lib.fa \
  population.insertions.fasta \
  2> RepeatMasker.insertions.log

perl classify_by_lib_RM.pl \
  -seq population.insertions.fasta \
  -RM population.insertions.fasta.out \
  -cov 80 -len 80 -iden 80
```

The files `RM.all.list` and `false.list` generated by `classify_by_lib_RM.pl` can be used to distinguish classified TE-derived insertions from unclassified insertion sequences.

## Step 6. Prepare TAP/TIP variants for gene-position annotation

The following command converts TAP/TIP records to VEP six-column Ensembl-style input.

```bash
awk 'BEGIN{OFS="\t"}
$4 == "INS" {print $1, $2, $2 + 1, "-", "+", "INS" NR}
$4 == "DEL" {print $1, $2, $2 + $3, "-", "+", "DEL" NR}
' population.PAV.summary.filtered.tsv \
  > population.TAP_TIP.vep.input.txt
```

## Step 7. Run VEP annotation

```bash
vep \
  --format ensembl \
  -i population.TAP_TIP.vep.input.txt \
  --gff Wm82.gff3.gz \
  --fasta Wm82.fasta.gz \
  --stats_file population.TAP_TIP.vep.stats \
  --output_file population.TAP_TIP.vep.annotation.txt
```

## Step 8. Clean VEP output

```bash
grep -v '^#' population.TAP_TIP.vep.annotation.txt \
  | awk 'BEGIN{OFS="\t"} {print $1, $2, $3, $4, $7}' \
  | sort -u \
  > population.TAP_TIP.vep.annotation.clean.tsv
```
