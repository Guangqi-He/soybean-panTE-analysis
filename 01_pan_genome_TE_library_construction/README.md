# Pan-genome TE Library Construction and Genome Re-annotation

This directory contains the workflow used to construct a soybean pan-genome transposable element (TE) library, refine TE family classification, and re-annotate individual genomes with the final pan-genome TE library.

The workflow consists of five major steps:

1. Convert an element-level TE library into a family-level TE library.
2. Perform de novo TE annotation for each soybean genome using EDTA.
3. Construct a pan-genome TE library using PanEDTA.
4. Reclassify unknown TE sequences using DeepTE or an equivalent TE classifier.
5. Re-annotate each genome using the final pan-genome TE library.

> **Note:** File names in the commands below use `Wm82` as an example. Replace them with the corresponding genome, annotation, CDS, and TE library files for each accession.

---

## 1. Required software

The following software and scripts are required:

- [EDTA](https://github.com/oushujun/EDTA)
- `cleanup_tandem.pl` and `cleanup_nested.pl` from the EDTA utility directory
- `panEDTA.sh`
- TBtools or TBtools command-line utilities
- `seqkit`
- DeepTE or another TE classification tool
- RepeatMasker
- Java runtime environment

---

## 2. Input files

Prepare the following input files before running the workflow:

| File | Description |
| --- | --- |
| `SoyBase_TE.curated.fa` | Curated SoyBase TE library used as the initial seed library |
| `Wm82.fasta` | Genome assembly FASTA file |
| `Wm82.gff3` | Genome annotation file in GFF3 format |
| `Wm82.cds.rep` | Representative CDS sequence file extracted from the genome annotation |
| `genome.list` | List of genomes and optional CDS files used by PanEDTA |
| `pan.TElib.fa` | Pan-genome TE library generated by PanEDTA |

---

## 3. Workflow

### 3.1 Convert the element-level TE library into a family-level TE library

First, remove tandem repeats and nested TE fragments from the curated SoyBase TE library.

```bash
EDTA/util/cleanup_tandem.pl -f SoyBase_TE.curated.fa -misschar N -nc 50000 -nr 0.9 -minlen 100 -minscore 3000 -trf 1 -cleanN 1 > SoyBase_TE.curated.cln.fa
```

Then remove nested TE sequences:

```bash
EDTA/util/cleanup_nested.pl -in SoyBase_TE.curated.cln.fa -threads 24
```

Use the resulting cleaned and non-redundant TE library as the curated seed library for EDTA. In the following commands, this final seed library is referred to as:

```text
SoyBase_TE.curated_redup.fa
```

If the actual output file from `cleanup_nested.pl` has a different name, rename it accordingly or update the commands below.

---

### 3.2 Prepare representative CDS sequences for each genome

Because PanEDTA integrates TE candidates across multiple genomes, gene-like TE sequences may increase if host genes are not properly filtered. Therefore, a matched CDS file should be provided for each genome whenever possible. If a genome-specific CDS file is unavailable, use the CDS file from the closest related accession.

#### 3.2.1 Generate a representative GFF3 file

```bash
java -cp TBtools_JRE1.6.jar biocjava.bioDoer.GXFUtils.GXFToRepresentativeGXF --inGXF Wm82.gff3 --outRepresentativeGff3 Wm82.gff3.rep
```

#### 3.2.2 Extract representative CDS sequences

```bash
java -cp TBtools_JRE1.6.jar biocjava.bioIO.GFF.ExtractFeaturefromGFF3andGenome --inGtf Wm82.gff3.rep --inGenome Wm82.fasta --outFile Wm82.cds.rep --targetFeature CDS --targetIdTag Parent --onlyCheck false
```

---

### 3.3 Perform de novo TE annotation for each genome using EDTA

Run EDTA for each genome using the curated seed TE library and the corresponding representative CDS file.

```bash
EDTA.pl --genome Wm82.fasta --cds Wm82.cds.rep --curatedlib SoyBase_TE.curated_redup.fa --anno 1 --u 1.5e-8 --threads 48
```

Repeat this step for all genomes included in the pan-genome analysis.

---

### 3.4 Construct the pan-genome TE library using PanEDTA

Create a `genome.list` file. Each row should contain a genome FASTA file and, when available, its corresponding CDS file. Missing CDS files are allowed, but providing matched CDS files is recommended.

Example `genome.list`:

```text
Wm82.fasta	Wm82.cds.rep
a.fasta	a.cds.rep
b.fasta
```

Run PanEDTA:

```bash
bash panEDTA.sh -g genome.list -c Wm82.cds.rep -t 64
```

The PanEDTA output library is referred to as:

```text
pan.TElib.fa
```

---

### 3.5 Reclassify unknown TE sequences in the pan-genome TE library

Unknown TE sequences in `pan.TElib.fa` can be reclassified using DeepTE or another TE classification tool.

Set the pan-genome TE library file name:

```bash
PAN_TELIB=pan.TElib.fa
```

#### 3.5.1 Extract unknown TE IDs

Use case-insensitive matching to capture both `unknown` and `Unknown` in TE headers.

```bash
grep -i "unknown" "${PAN_TELIB}" | sed 's/^>//' > TE_unknown.id
```

Summarize the unknown TE categories:

```bash
cut -d'#' -f2 TE_unknown.id | sort | uniq -c
```

Example output:

```text
4 LINE/unknown
737 LTR/unknown
28 SINE/Unknown
```

Extract all unknown TE sequences:

```bash
seqkit grep -f TE_unknown.id "${PAN_TELIB}" -o TE_unknown.fa
```

#### 3.5.2 Split unknown TE sequences by major TE order

```bash
seqkit grep -r -p 'LTR' TE_unknown.fa -o TE_LTR_unknown.fa
seqkit grep -r -p 'SINE' TE_unknown.fa -o TE_SINE_unknown.fa

seqkit grep -r -p 'LINE' TE_unknown.fa -o TE_LINE_unknown.fa
```

#### 3.5.3 Retain known TE sequences

```bash
grep '^>' "${PAN_TELIB}" | grep -vi "unknown" | sed 's/^>//' > TE_known.id
seqkit grep -f TE_known.id "${PAN_TELIB}" -o TE_known.fa
```

### 3.6 Download and prepare the DeepTE plant model

Download the plant model provided for DeepTE:

```bash
wget -c https://de.cyverse.org/dl/d/89D2FE7A-41BA-4F64-80E2-B9C26D49E99F/Plants_model.tar.gz
```

Extract the model archive:

```bash
tar -zxvf Plants_model.tar.gz
```

Set the model directory. Modify this path according to your local installation.

```bash
DEEPTE_MODEL=/tool/DeepTE/Plants_model
```

---

### 3.7 Run DeepTE for SINE, LINE, and LTR unknown sequences

#### SINE

```bash
python DeepTE.py -i TE_SINE_unknown.fa -sp P -m_dir "${DEEPTE_MODEL}" -fam SINE > DeepTE_SINE.log 2>&1
```

#### LINE

```bash
python DeepTE.py -i TE_LINE_unknown.fa -sp P -m_dir "${DEEPTE_MODEL}" -fam LINE > DeepTE_LINE.log 2>&1
```

#### LTR

```bash
python DeepTE.py -i TE_LTR_unknown.fa -sp P -m_dir "${DEEPTE_MODEL}" -fam LTR > DeepTE_LTR.log 2>&1
```

The following commands assume that the DeepTE-classified FASTA files are named as follows:

```text
SINE_DeepTE.fasta
LINE_DeepTE.fasta
LTR_DeepTE.fasta
```

If DeepTE generates output files with different names, rename the corresponding FASTA files before running the next step.

---

### 3.8 Clean DeepTE output headers

Remove redundant DeepTE prefixes from classified TE headers.

#### SINE

```bash
sed -i 's/Unknown__ClassI_nLTR_SINE_//1' SINE_DeepTE.fasta
```

#### LINE

```bash
sed -i 's/unknown__ClassI_nLTR_LINE_//1' LINE_DeepTE.fasta
```

#### LTR

```bash
sed -i 's/unknown__ClassI_LTR_//1' LTR_DeepTE.fasta
sed -i 's/unknown__ClassI_LTR/unknown/1' LTR_DeepTE.fasta
```

---

### 3.9 Merge known and reclassified TE sequences

Merge the known TE sequences and the DeepTE-reclassified unknown TE sequences into the final pan-genome TE library.

```bash
cat TE_known.fa LTR_DeepTE.fasta SINE_DeepTE.fasta LINE_DeepTE.fasta > panTE_DeepTE_final.lib.fa
```

The final TE library is:

```text
panTE_DeepTE_final.lib.fa
```

---

### 3.10 Re-annotate each genome using the final pan-genome TE library

Use RepeatMasker with the final pan-genome TE library.

```bash
RepeatMasker -e ncbi -pa 24 -q -div 40 -lib panTE_DeepTE_final.lib.fa -cutoff 225 -gff Wm82.mod.panEDTA > /dev/null
```

Then run the final EDTA annotation step using the RepeatMasker output.

```bash
EDTA.pl --genome Wm82.fasta -t 48 --step final --anno 1 --curatedlib panTE_DeepTE_final.lib.fa --cds Wm82.cds.rep --rmout Wm82.mod.panEDTA.out --overwrite 1
```

Repeat this re-annotation step for all genomes included in the pan-genome analysis.

---

## 5. Important notes

1. **CDS filtering is strongly recommended.** Providing genome-specific CDS files helps reduce false-positive gene-like TE annotations during EDTA and PanEDTA analyses.
2. **Use consistent file names.** The commands above use `TE_unknown` consistently. Avoid mixing names such as `TE_unknow`, `panTE_unknow`, and `TE_unknown`.
3. **Use case-insensitive filtering for unknown TEs.** TE headers may contain either `unknown` or `Unknown`.
4. **Check DeepTE output names.** DeepTE output file names may differ depending on the local installation or wrapper script. Rename them to `SINE_DeepTE.fasta`, `LINE_DeepTE.fasta`, and `LTR_DeepTE.fasta` before merging.
5. **Replace example genome names.** The `Wm82` commands should be repeated and modified for each genome in the pan-genome analysis.
6. **Use the correct RepeatMasker input.** `Wm82.mod.panEDTA` represents the genome sequence file used for RepeatMasker in this workflow. Replace it with the corresponding modified genome file for each accession.

## 6. Suggested citation in downstream analysis

When using the final pan-genome TE library in downstream analyses, report the library file name and the major construction steps, for example:

```text
A soybean pan-genome TE library was constructed by integrating EDTA-based genome-level TE annotations across multiple soybean assemblies using PanEDTA. Unknown TE sequences in the pan-genome library were further reclassified using DeepTE, and the final curated pan-genome TE library was used to re-annotate each genome with RepeatMasker and EDTA.
```
